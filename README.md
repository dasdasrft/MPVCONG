一套专为 **现代观影、高码率流媒体网盘播放、4K HDR、以及极速无损视频剪辑** 深度调优的 MPV 便携式独立配置套件。

全套配置秉承 **“极致纯净、纯原生驱动、零多余开销”** 的设计哲学，彻底剔除冗长无用指令，带来开箱即用的专业影音体验。

---

## ✨ 核心特性

### 1. 📺 YouTube 官方级默认字幕规范
- **官方视觉复刻**：采用 `Segoe UI / 微软雅黑` 现代无衬线字体，字号 34，搭配 `#FFFFFF` 纯白文字与常规字重（Regular）。
- **75% 不透明度黑底盒 (`background-box`)**：彻底阻绝雪景、反光或复杂高亮背景对字幕的侵蚀，全场景清晰可读。
- **物理极限沉底 (`sub-pos=100` + `sub-margin-y=12`)**：字幕紧凑自然地沉在画面最底端，最大化释放正片主体的视觉空间。
- **纯原生毫秒平滑淡入 (`sub-filter-regex`)**：无需任何外部复杂定时器脚本，直接由底层 libass 硬件渲染管道注入 200ms 平滑渐显与 100ms 渐隐，绝无字幕跳动、撕裂或半句错位问题。

### 2. ⚡ 强劲的流媒体与网盘缓冲体系
- **1GB 极速前向预读 (`demuxer-max-bytes=1073741824`)**：配合 512MB 后向回退缓存，完美支持 CloudDrive2 / Alist 挂载盘（如 115 网盘、WebDAV）大码率 4K REMUX 拖动秒开、不卡顿。
- **安全硬件解码 (`hwdec=auto-safe`)**：充分发挥 GPU 硬件加速解码效能，降低整机发热与功耗。
- **状态与音量断点记忆**：关闭播放器时自动记录播放进度、音轨、字幕轨，并实时持久化保存当前设置的音量与静音状态，换集或重新打开不再炸耳朵。

### 3. 🖱️ 现代清爽窄版右键菜单 (`menu.conf`)
- **宽度收窄 50%**：精炼各项文本，彻底告别撑开大半个屏幕的笨重视感。
- **呼吸感层级架构**：高频功能直达（字幕、音轨、倍速、画质映射、截图），低频参数优雅归类。
- **全内置命令驱动**：点击即生效，支持 HDR 映射曲线切换（Spline / BT.2446a）、夜间防打扰（DRC 动态压缩）、对白增强与视频旋转比例调整。

### 4. ✂️ 极速切片与硬件压制合一 (`cut_and_burn.lua`)
- **秒级无损切片**：键盘按 `c` 标记起点，再按 `c` 标记终点，秒级无损截取精彩片段。
- **AMD AV1 硬件编码**：按 `Ctrl + b` 调用 RX 9070 XT (AMF) / NVENC 启动 AV1 硬件加速硬字幕压制。
- **独立音轨无损提取**：按 `Ctrl + e` 一键将当前视频原声抽取为独立 320k 高品质 MP3。

## ⌨️ 常用快捷键速查

| 按键 | 功能说明 |
| :---: | :--- |
| **`Space`** | 播放 / 暂停 |
| **`→` / `←`** | 快速前进 / 后退 5 秒 |
| **`Shift + →` / `←`** | 精确微调跳转 1 秒 (关键剪辑定位) |
| **`\`** | 在 **2.5x 快速阅览** 与 **1.0x 原速** 之间一键切换 |
| **`Backspace`** | 瞬时恢复 1.0x 原速 |
| **`y`** | **原生平滑淡入动效** 一键开启 / 关闭 |
| **`Alt + u`** | **一键重置为 YouTube 默认字幕** (贴底黑底盒样式) |
| **`U` (`Shift + u`)** | 强制覆盖 / 恢复 ASS 特效字幕样式 |
| **`m`** | 一键静音 / 恢复声音 |
| **`Enter` / `双击左键`** | 进入 / 退出全屏播放 |
| **`鼠标右键`** | 唤起现代清爽右键全功能上下文菜单 |
| **`Tab`** | 常驻开启 / 关闭详细硬件性能与丢帧统计面板 |
| **`c`** | 标记视频无损切片起点 (A) / 终点 (B) |
| **`Ctrl + b`** | 启动 GPU 硬件硬字幕压制 (AV1) |
| **`Ctrl + e`** | 一键抽取原声音轨为 320k MP3 |

## 🚀 安装与使用方式

1. 确保已安装 [MPV 播放器](https://mpv.io) (推荐 64 位最新版本)；
2. 下载本仓库内容；
3. 将所有文件复制并覆盖到你的 MPV 配置目录：
   - **便携版 (Portable)**：`MPV安装目录/portable_config/`
   - **系统安装版**：`%APPDATA%/mpv/`
4. 打开 MPV 即可享受纯净丝滑的现代观影体验！
