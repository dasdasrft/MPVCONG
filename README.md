# MPV Portable Configuration

专为 **4K 高码率流媒体、极简纯净性能流与高效视频处理** 深度定制的 MPV 独立配置套件。

---

## ⚡ 核心调校与特性

- **1.5GB 超大解复用缓存**：
  分配 `1024MB` 前向预读与 `512MB` 后向回退缓存（`demuxer-max-bytes`），专为高码率 4K REMUX、网盘挂载（115 / CloudDrive2 / Alist）及局域网 WebDAV 流媒体调优，大幅减少 Seek 缓冲等待。
- **纯净性能取向**：
  采用 `scale=nearest` 极低开销纯净缩放与 `hwdec=auto-safe` 硬解；移除系统原生标题栏（`title-bar=no`），禁用默认原生粗糙进度条，实现极简沉浸视窗。
- **YouTube 规范沉底字幕 & 原生平滑淡入**：
  - 默认对齐 YouTube 官方字幕规范：无衬线字体 + 75% 不透明度黑底盒（`background-box`），阻绝复杂高亮背景干扰。
  - 极限物理贴底（`sub-pos=100` + `sub-margin-y=12`），绝不侵占正片主体画幅。
  - 基于底层 `sub-filter-regex` 注入 `\fad(200,100)` 毫秒级原生淡入淡出，零脚本常驻开销，彻底根治多行双语字幕错位、闪烁或漂移问题。
- **极简窄版右键菜单 (`menu.conf`)**：
  宽度较原生菜单收窄 50% 以上，纯原生命令驱动，集成 Deband 去色带、HDR 映射模式（Spline / BT.2446a / Clip）、音频 DRC 动态范围压缩与对白增强。
- **GPU 硬件硬字幕压制 & 无损切片合一 (`cut_and_burn.lua`)**：
  集成 1100+ 行音视频处理工作流，支持视频秒级无损切片、AMD AMF (AV1) / NVENC / QSV 硬件加速硬字幕压制与独立 320k 音轨一键提取。

## ⌨️ 特色快捷键

> 基础通用按键（空格暂停、方向键快进退、全屏退出等）遵循标准逻辑，以下仅列出专属特色映射：

| 快捷键 | 功能 |
| :---: | :--- |
| `\` | **2.5x 高速略读 / 1.0x 原速** 一键往返切换 |
| `Backspace` | 瞬时恢复 1.0x 原速 |
| `Shift + → / ←` | **精确微调 1 秒**（非模糊跳转，剪辑定位必备） |
| `y` | **原生平滑淡入动效** 一键开启 / 关闭 |
| `Alt + u` | 一键重置为 **YouTube 默认贴底黑底盒样式** |
| `U` (`Shift + u`) | 强制覆盖 / 恢复 ASS 特效字幕样式 |
| `c` | 标记切片起点 (A) / 终点 (B) 并秒级无损导出 |
| `C` (`Shift + c`) | 清除当前切片起止点标记 |
| `Ctrl + b` | 调用 GPU 硬件编码器启动 **AV1 硬件硬字幕压制** |
| `Ctrl + e` | 一键抽取当前音轨为独立 320k MP3 |
