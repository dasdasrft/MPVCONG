# MPV 增强更新套件与全能音视频下载助手 (MPVCONG)

一个专为 Windows 平台打造的 **MPV 播放器自动更新套件** 与 **全网音视频极速下载助手**。内置国内网络分流优化、智能本地代理探测及多镜像源加速，旨在为 MPV 爱好者提供无痛、省心的一站式媒体工具集。

---

## 🌟 核心特性

### 1. MPV 智能在线更新器 (`updater.bat`)
* **双引擎兼备**：优先调度现代 PowerShell Core (`pwsh`)，自动向下兼容系统自带的 `PowerShell 5.1`，无需繁杂配置。
* **智能代理与国内镜像加速**：
  * 自动探测本地常见代理端口（如 Clash `7890`/`7897`、v2ray `10808`/`10809` 等）与系统环境变量。
  * 若未检测到本地代理，自动无缝切换至多条国内 GitHub 公共加速镜像源（`gh-proxy.com`、`ghproxy.net`、`ghfast.top`），彻底解决 Windows 下 MPV 无法更新或拉取缓慢的问题。
* **自愈与规整**：更新完成后自动清理临时包与冗余脚本，保证 MPV 根目录干净利落。

### 2. 全网万能音视频下载器 (`xiazai.bat` / `youtube_downloader.py`)
* **全平台广泛兼容**：基于现代 yt-dlp 核心封装，原生深度适配 YouTube、哔哩哔哩 (Bilibili/b23.tv)、微博、抖音、X (Twitter)、快手、小红书等 1800+ 主流音视频站点。
* **智能国内外分流**：
  * 国内站点（B站、微博、抖音等）**自动直连极速下载**，规避因海外代理 IP 触发的地区版权限制与限速；
  * 海外站点（YouTube、X 等）**自动通过代理**，告别网络连接失败。
* **终极画质与防降级防护**：
  * 智能规避 YouTube SABR 协议拦截与 360p 画质降级。
  * 自由选择最高画质（4K / 2K / 1080p60 / HDR）及优先编码（AV1 / VP9 / H.264）。
* **MPV 专属：双语字幕融合引擎**：
  * 自动抓取官方字幕或 ASR 自动翻译字幕，毫秒级对齐时间轴。
  * 永久生成独立中英 `[视频名].双语.srt` 文件，直接丢给 MPV 即可自动挂载同名字幕。
* **多线程并发切片加速**：支持多片段并发多线程下载（`--concurrent-fragments`），榨干宽带下行速率。
* **全模式快捷直达**：
  * 快捷提取：仅下独立封面（`c`）、仅下提取字幕（`z`）、仅转高品质音频（MP3 / M4A / WAV 等）（`a`）。
  * 剧集防误触：智能识别单视频与播放列表/多P分集，避免误下载几十集长列表。

## 🚀 快速上手

### 依赖环境准备
1. **操作系统**：Windows 10 / 11 (64-bit)
2. **Python 环境**：Python 3.8+（运行视频下载助手需安装，并勾选 `Add Python to PATH`）
3. **播放器本体**：将此工具集放置在你的 `MPV` 便携根目录下即可协同使用。

---

### 一、使用 MPV 自动更新器
1. 直接双击运行 `updater.bat`。
2. 脚本将自动检测环境并定位根目录，智能测试网络后拉取最新版本 MPV 核心组件。
3. 更新完成后按任意键即可退出，播放器将保持最新状态。

---

### 二、使用全能音视频下载助手
1. 双击运行 `xiazai.bat`。
2. **输入链接**：
   * 粘贴视频网页链接（支持 YouTube 视频、B站链接或短链如 `https://b23.tv/...`、BV号如 `BV1xx411c7xx` 等）。
3. **选择功能模式**：
   * 输入对应序号可直接开始最佳画质下载。
   * 支持快捷模式：输入 `c` 仅下载封面；输入 `a` 仅提取音频；输入 `z` 仅提取双语字幕。
4. **下载产物**：
   * 默认自动归整保存在同目录的 `downloads/` 文件夹中。
   * 包含封装好的视频文件、独立封面与配套的 `.双语.srt` 字幕。

## ⚙️ 高级配置与自定义

下载助手的首次运行将自动在根目录生成 `ytdl_config/config.json` 配置文件，可随时修改：

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `proxy_port` | `7890` | 本地海外代理端口（如下载 YouTube 时使用） |
| `concurrent_fragments` | `5` | 切片并发数（推荐 4~8，可充分跑满带宽） |
| `bilingual_subs` | `true` | 是否自动生成毫秒级中英双语字幕 |
| `embed_chapters` | `true` | 是否将 YouTube/视频章节标记内嵌进视频流中 |
| `container` | `"mp4"` | 默认视频封装格式（可选 `mp4` 或 `mkv`） |

## 💡 常见问题与贴士 (FAQ)

* **Q: 为什么下载国内 B 站视频时速度很快，但下载 YouTube 总是连不上？**
  * 请确保本地科学上网软件已开启本地监听端口（默认探测 `7890` / `7897` 等），下载器会自动将 YouTube 流量导向代理，而国内站点会自动直连。
* **Q: 下载好的视频如何自动加载双语字幕？**
  * 下载器生成的字幕与视频文件名严格保持一致（`[视频名].双语.srt`），只要在同目录下，用 MPV 打开视频时即会自动挂载中英双语字幕。
* **Q: 运行 `xiazai.bat` 提示找不到 Python？**
  * 请前往 [python.org](https://www.python.org/) 下载安装 Python，安装时切记勾选底部的 **"Add python.exe to PATH"**。
