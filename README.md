# MPV Portable Configuration

一套轻量、纯净且面向现代观影与音视频处理工作流的 **MPV 便携式配置套件**。

本配置方案以 **极致性能、极简视觉与纯原生指令** 为核心，在提供 1GB 超大流媒体缓存、低开销硬件加速与现代化窄版交互菜单的同时，内嵌了完整的 **视频无损切片、音轨抽取与 GPU 硬件字幕压制工作流**。

---

## 架构与核心特性

### 1. 播放引擎与渲染调校 (`mpv.conf`)
- **硬件解码优先**：采用 `hwdec=auto-safe` 模式，优先调用 GPU 安全硬件解码管道（D3D11VA/Vulkan），显著降低高码率 4K 片源的 CPU 负载与发热。
- **超大解复用器缓存**：配置 **1024MB (1GB) 前向预读缓存** 与 **512MB 后向回退缓存**，极大提升本地超高码率片源以及网络流媒体（WebDAV / 网盘挂载盘 / 局域网共享）的拖动与 Seek 响应速度。
- **纯净沉浸式窗口**：彻底移除原生系统标题栏（`title-bar=no`），启用窗口智能边缘贴靠吸附（`snap-window`），禁用默认粗糙的 OSD 进度条（`no-osd-bar`），并优化控制面板死区触发。
- **智能资源索引与列表构建**：拖入或打开目录时自动递归扫描子文件夹（`directory-mode=recursive`），过滤并仅载入视频文件生成播放列表；支持外挂中文字幕与音轨的模糊智能匹配（`sub-auto=fuzzy` / `audio-file-auto=fuzzy`）。
- **状态与音量持久化记忆**：退出播放器时精准记录播放进度时间戳、音轨、字幕轨选择，并完整记忆当前音量与静音状态。
- **独占输入接管**：彻底屏蔽 MPV 源码内置的过时按键行为（`input-builtin-bindings=no` / `input-default-bindings=no`），完全由自定义按键表独立接管。

### 2. 现代紧凑型右键上下文菜单 (`menu.conf`)
- **窄版极简布局**：彻底重构原生菜单文本，将菜单宽度收窄 50% 以上，避免遮挡观影视线。
- **全内置指令驱动**：不依赖任何冗余第三方插件，纯原生指令响应，点击即生效。
- **集成功能矩阵**：
  - **字幕系统**：主/次字幕轨切换、ASS 特效覆盖、平滑淡入动效开关、预设样式直选（YouTube 默认/护眼柔白/暖调琥珀/番剧印刷）以及字体字号/位置/延迟微调。
  - **音频处理**：音轨与输出设备切换、夜间防打扰模式（`loudnorm` DRC 动态压缩）、对白人声动态增强（`dynaudnorm`）。
  - **画质与色彩**：去色带滤镜（Deband 消除色彩断层）、去隔行、SDR 转 HDR 反向色调映射、HDR 色调映射算法（Spline / BT.2446a / Auto）。
  - **实用工具**：无损原画截图与带字幕截图、剪贴板路径直播与追加、硬件统计面板唤起。

### 3. 高频直觉按键系统 (`input.conf`)
- **核心操作精简**：保留最符合人类直觉的本能按键（空格暂停、方向键跨步、Shift 键 1 秒精准逐帧微调）。
- **极速阅览模式**：按 `\` 键在 2.5x 高速略读与 1.0x 原速间一键往返，按 `Backspace` 瞬间归位原速。
- **零冲突按键**：为常用字幕重置、平滑淡入开关、全屏置顶等功能分配独立快捷键，彻底避免与视频剪辑热键冲突。

### 4. 视频无损切片与 GPU 硬件压制 (`cut_and_burn.lua`)
内置了 1100+ 行的全功能视频处理工作流脚本：
- **视频无损极速切片**：播放中按 `c` 标记剪辑起点，再次按 `c` 标记终点，秒级无损导出片段至 `cutfragments/` 目录；按 `C` (`Shift + c`) 清空标记。
- **GPU 硬件硬字幕压制**：按 `Ctrl + b` 一键调用本机 GPU 编码器（支持 AMD AMF AV1/H.264、NVIDIA NVENC、Intel QSV）进行硬件加速硬字幕压制，支持智能音轨映射与 CFR 帧率锁定。
- **独立原声音轨提取**：按 `Ctrl + e` 一键将当前视频的原声音轨抽取导出为 320k 高品质 MP3。
- **智能路径容错**：自动剥离浏览器/桌面拖拽产生的 `file://` 协议头与 URL 百分号编码，完美兼容在线流媒体与复杂本地路径。

## 部署与使用

1. 安装 [MPV 官方播放器](https://mpv.io)；
2. 下载本仓库，将所有文件复制到 MPV 的配置路径：
   - **便携版 (推荐)**：解压并放置于 `mpv.exe` 同级目录下的 `portable_config/` 文件夹中；
   - **安装版**：放置于系统 `%APPDATA%/mpv/` 目录；
3. 直接运行 MPV 即可生效。
